**Descripción del proyecto**

Este proyecto se desarrolla como práctica de la asignatura de Estructuras de Datos, con el propósito de aplicar de forma concreta los conceptos vistos en clase. Consiste en la construcción de una aplicación que permite almacenar, organizar y manipular información mediante el uso de estructuras de datos, garantizando un manejo eficiente de la información y operaciones de inserción, búsqueda, recorrido y eliminación de elementos.

A lo largo del desarrollo se implementan y comparan distintas estructuras (como listas, pilas, colas, árboles o tablas hash), analizando su comportamiento, ventajas y limitaciones según el problema a resolver. De esta manera, el proyecto busca no solo cumplir con un requerimiento funcional, sino también comprender el impacto que tiene la elección de una estructura adecuada sobre la eficiencia y el rendimiento del programa.

Como resultado, se espera obtener una solución funcional y bien documentada que evidencie el dominio de los conceptos fundamentales de estructuras de datos y su aplicación práctica en el desarrollo de software.
